# M15.14 artifacts

- `r46h-geos-arm-m15.14.tar.gz` — clean source package, top-level directory `r46h-geos-arm/`
- `build-m15.14-fast.sh` — standalone incremental R46H builder

SHA-256 values are in `M15.14-SHA256SUMS.txt`.

The source archive intentionally excludes third-party D64/PDF material, the historical GEOS2000 tarball, stock R46H kernel modules/DTBs, generated SD images and compiler outputs. Their reference hashes/provenance are documented in `docs/SOURCES-AND-HASHES.md`.
